# eLogix ERP - Analytics (Phase 8)

|                 |                                                                                                                                                                                                                            |
| --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Status          | Implemented locally, awaiting check-only validation                                                                                                                                                                        |
| Scope           | Native Salesforce report types, reports and dashboards for implemented data only. No custom dashboard LWC, no Apex.                                                                                                        |
| Source of truth | `scripts/node/model/elogix-analytics.mjs`, generated by `npm run metadata:generate` (writer: `scripts/node/lib/analytics-writer.mjs`). The generator checks every report field against its report type and the data model. |

## 1. Decisions (2026-11-20)

- **Fixed running user.** All five dashboards are `SpecifiedUser` dashboards that run as one administrator. Viewers see org-wide totals; drilling into a report shows only the records the viewer can access. The username is never stored in the model: set `ELOGIX_DASHBOARD_RUNNING_USER` when generating (section 5). Developer Edition allows only a few dynamic dashboards, and the architecture already chose a fixed running user (SOLUTION_ARCHITECTURE section 6).
- **On-time KPI.** New formula field `Shipment__c.Is_On_Time__c` (checkbox, read-only for every role): `Actual_Delivery_Date__c <= Expected_Delivery_Date__c`, with both dates set. It is also on the Shipment page layout.
- **No invented finance metrics.** Invoices and payments are not implemented (Phase 5B). "Delivered Freight Value" is `Freight_Amount__c` of delivered or closed shipments (`Is_Billable__c`), and quotation value is `Total_Amount__c`. There is no outstanding-invoice metric.

## 5. Access

- **Folders:** the Reports folder remains shared **View** with the `AllInternalUsers` group; reports execute as the viewer. The local Phase 9 model restricts the Dashboards folder to the Logistics Manager role because dashboards run as a fixed administrator and show org-wide totals. Editing stays with administrators. The role-restricted dashboard folder is not deployed or org-verified yet.
- **Reports** run as the viewer, so CRUD, FLS and sharing apply. Users need the **Run Reports** user permission; the Standard Platform User profile used for eLogix users is expected to have it, which the verification checks.
- **Dashboards** run as the fixed running user. Anyone who can open the dashboard folder sees the same totals. This is the accepted trade-off of the fixed-running-user decision; Phase 9 can restrict the folder to manager roles.

## 6. Generate, validate and verify

```powershell
# Optional: set the running user (an active administrator's username) before generating.
# Without it the <runningUser> element is omitted; if the org rejects that, set it and regenerate.
$env:ELOGIX_DASHBOARD_RUNNING_USER = "<admin username>"
npm run metadata:generate
npx prettier --write "force-app/main/default/reports/**/*.xml" "force-app/main/default/dashboards/**/*.xml" "force-app/main/default/reportTypes/**/*.xml"

sf project deploy validate --source-dir force-app --test-level RunLocalTests --target-org eLogixDev --wait 60
```

Manual verification after deployment:

1. App Launcher → **Reports** → folder **eLogix Reports**: all 19 reports run without errors. With little data they may be empty; Phase 9 seeds demo data.
2. Create one Delivered shipment through the UI (or use an existing one), then check:
   - **On-Time Delivery** shows it under true or false.
   - **Delivered Freight Value by Month** shows its freight.
3. **Dashboards** → folder **eLogix Dashboards**: open each of the 5 dashboards and click **Refresh**. Every component renders, and clicking one opens its report.
4. Log in as a role user (for example Sales Executive):
   - The dashboards open with the same totals (fixed running user).
   - Reports show only records that user can see.
